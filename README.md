purpose
    This project uses JavaScript functions to manage basic event information, including fees, duration, capacity, and event summaries.

Setup
    run node Utility_lib.js

Operation
    The program uses the event name, capacity, fee, number of attendees, start time, end time, and number of people registered to calculate and display event information. Each function does its job and prints the result using console.log().

Known Limitations
    The inputs entered into the function are not stored anywhere so the inputs are lost if not hard coded in.

Difficult decision
    The hardest part of this assignment was figuring out what inputs to use to get the results I needed
